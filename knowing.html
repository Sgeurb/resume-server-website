01 / PROJECT OVERVIEW

Small application.
Real-world development.

Knowing began as a simple desktop ticker that displayed facts from a predefined list. Version 3.0 expands the application by retrieving trivia from an online API, managing background network requests, and handling situations where the internet connection is unavailable.

Live Internet Facts

Knowing uses a public trivia API to retrieve facts about science, history, animals, technology, and other subjects.

Scrolling Desktop Ticker

Facts move across the desktop from right to left, displaying each fact only once.

Background Processing

PowerShell background jobs retrieve facts without blocking the Windows Forms interface.

Offline Support

When the API cannot be reached, Knowing uses a local collection of backup facts.

Duplicate Detection

Knowing tracks previously displayed facts during the current session to reduce repetition.

Desktop Integration

The application uses a borderless, draggable, always-on-top window that can be closed with its X button.

How Knowing Works

  1. Knowing starts and requests a random fact from the internet.
  2. PowerShell processes the API response and extracts the fact text.
  3. Windows Forms displays the fact in the scrolling ticker.
  4. The fact scrolls across the ticker once.
  5. After approximately 90 seconds, Knowing requests another fact.
  6. If the API fails, an offline backup fact is displayed instead.
03 / INSTALLATION

Download.
Run. Learn.

Knowing 3.0 is designed for Windows computers running Windows PowerShell 5.1. It requires an internet connection for live trivia, but can display offline backup facts.

  1. Download the Knowing 3.0 PowerShell script.
  2. Save the file as Knowing3.0.ps1 in a folder you can easily find.
  3. Review the source code before running it.
  4. Open Windows PowerShell and navigate to the folder containing the script.
  5. Run the script using the command below. 
powershell.exe -NoProfile -STA -File ".\Knowing3.0.ps1"
Security note: PowerShell scripts should be reviewed before execution. Knowing retrieves public trivia from an external API. No administrator privileges are required for normal use.

Launch Without Keeping the Terminal Open

To start Knowing independently, run the following command in PowerShell from the folder containing the script. 

Start-Process powershell.exe -WindowStyle Hidden -ArgumentList '-NoProfile -STA -File "Knowing3.0.ps1"'

For reliable launching from any folder, replace the relative script filename with its complete Windows file path.
